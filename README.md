# Das Schweizer Schulsystem (Beispiel Aargau)

Interaktive Web-Präsentation für den Kurs Deutsch B1.1.

- Interaktive Grafik vom Kindergarten bis zur Hochschule (klickbare Blöcke mit Wortschatz DE → ES)
- Vier Beispielwege (Lena, Marco, Sara, Jonas)
- Vergleich Deutschland / Schweiz
- Quiz für die Klasse
- Sprechertext für 5 Minuten mit Timer

Öffnen: `index.html` im Browser (keine Installation nötig).
